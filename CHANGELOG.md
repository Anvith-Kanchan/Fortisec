# Changelog

All notable changes to this project will be documented in this file.

This project follows semantic versioning.

## 0.1.2 - 2026-08-02

- Renamed the package and import namespace from `secutils` to `fortisec`.
- Added validators for email, IP, domain, hostname, URL, CIDR, and ports.
- Added hash identification helpers.
- Added entropy scoring helpers.
- Added log redaction for common secrets and identifiers.
- Added HTTP security header scanner.
- Added safe path utilities.
